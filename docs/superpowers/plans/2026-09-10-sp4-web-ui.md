# SP4 Master Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the HillGrow master a phone-usable web UI served from its own flash: Wi-Fi manager (AP+STA), login, a command-line-over-HTTP API plus a 2 s state snapshot, field-table-driven config JSON, alarms, master/zone firmware upload and the fleet update button, on the SP3 bench rig.

**Architecture:** Approach A from the design doc — every action is a CLI line through the existing `cmd_core` dispatcher (`POST /api/cmd`, HTTP session permanently locked), state is one JSON document polled every 2 s, config is the §4.6 field table rendered/merged by a pure `hg_json`, all served by one `esp_http_server` instance behind a cookie login. Pure components (`hg_mcfg`, `web_auth`, `hg_json`, `alarm_mgr`, `state_snap`, `time_core`, `http_routes`) are host-tested; glue (`wifi_mgr`, `time_svc`, `http_srv`, node_mgr additions) is bench-tested. Frontend is one gzipped vanilla-JS page set embedded with `EMBED_FILES`.

**Tech Stack:** ESP-IDF 6.0.1 (esp_http_server, esp_wifi APSTA, esp_sntp, app_update, esp_partition, mbedtls SHA-256), registry components `espressif/cjson` + `espressif/mdns` (master only), Unity host tests under MSVC with cJSON fetched by CMake, Python 3 tools (pyserial, urllib), vanilla ES2017 + CSS.

**Spec:** `docs/superpowers/specs/2026-09-10-sp4-web-ui-design.md` (binding system spec: `docs/superpowers/specs/2026-08-31-hillgrow-system-design.md` §4.6, §5.6, §6.1–6.4).

- Uploads: raw `application/octet-stream` body only; `Transfer-Encoding: chunked` → 400; `esp_app_desc.project_name` must be `hillgrow_master` / `hillgrow_zone`; `esp_task_wdt_add/reset/delete` around the write loop (rescue pattern) plus `vTaskDelay(1)` every 8 blocks.

`tools/web_pack.py`:
```python
#!/usr/bin/env python3
"""Gzip web/ assets into <out>/<name>.gz and enforce the SP4 size cap (spec: <= 64 KB compressed total).
Usage: web_pack.py --src web --out build/web [--cap 65536] [--selftest]"""
import argparse, gzip, os, sys, tempfile

ASSETS = ("index.html", "app.js", "app.css")

def pack(src, out, cap):
    os.makedirs(out, exist_ok=True)
    total = 0
    for name in ASSETS:
        with open(os.path.join(src, name), "rb") as f:
            data = f.read()
        gz = gzip.compress(data, compresslevel=9, mtime=0)   # mtime=0 -> reproducible bytes -> stable ETag
        total += len(gz)
        with open(os.path.join(out, name + ".gz"), "wb") as f:
            f.write(gz)
        print(f"{name}: {len(data)} -> {len(gz)} bytes")
    print(f"total compressed: {total} / {cap}")
    return total <= cap

def selftest():
    with tempfile.TemporaryDirectory() as d:
        src = os.path.join(d, "src"); os.makedirs(src)
        for n in ASSETS:
            with open(os.path.join(src, n), "w") as f: f.write("x" * 1000)
        assert pack(src, os.path.join(d, "out"), 65536) is True
        assert pack(src, os.path.join(d, "out2"), 10) is False
        print("selftest OK")

if __name__ == "__main__":
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--src", default="web"); ap.add_argument("--out", default="build/web")
    ap.add_argument("--cap", type=int, default=65536); ap.add_argument("--selftest", action="store_true")
    a = ap.parse_args()
    if a.selftest: selftest(); sys.exit(0)
    sys.exit(0 if pack(a.src, a.out, a.cap) else 1)
```

    char    ap_ssid[33];            /* 98  */
    char    ap_pass[65];            /* 131 */
