# SP3 Ring Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The UART ring: master + N zones exchange heartbeats, forwarded CLI commands, config sync, time, and fleet firmware updates per system spec §2, with the master's minimal AP serving `/fw/zone.bin`.

**Architecture:** One pure protocol component (`ring_proto`, host-TDD everything: framing, routing, tracker, telemetry codecs, config transfer, health) under a thin shared target link layer (`ring_link`); master-side orchestration in `node_mgr` + `node_store`; zone-side glue in `zone_ring`; the §3.10 OTA trial replaces SP1's mark-valid placeholder in both apps.

**Tech Stack:** ESP-IDF 6.0.1 (esp_driver_uart, esp_wifi AP, esp_http_server, esp_timer, nvs_flash), C11, Unity host tests (MSVC), python tools.

**Spec:** `docs/superpowers/specs/2026-09-02-sp3-ring-design.md` (SP3 decisions) arguing from `docs/superpowers/specs/2026-08-31-hillgrow-system-design.md` §2 (binding protocol), §3.10 (trial), §4.4 (reconciliation), §5.4 (vocabulary).

## Global Constraints

- C11; no file > ~300 lines; pure components include NO IDF headers; wire data packed little-endian by explicit byte offset with `_Static_assert`ed sizes; comments only where the why is non-obvious.
- Host tests: `cmake -S tests/host -B build/host -DCMAKE_BUILD_TYPE=Release` / `--config Release` / `ctest -C Release`; every new pure source joins a `hg_test()` executable; the gate stays wired into all three app builds.
- Ring wire format is spec §2.2–§2.4 EXACTLY: `wire = 0x00 + COBS(hdr[9] + payload[≤128] + crc16_le) + 0x00`; CRC-16/CCITT-FALSE (poly 0x1021, init 0xFFFF, check `0x29B1`) over header+payload, recomputed at every forwarding hop; header offsets 0 magic `0xA1` · 1 src · 2 dst · 3 type · 4 flags(b0 ACK_REQ) · 5 ttl(16, −1/hop, drop at 0) · 6 len · 7 seq u16 LE.
- Ids: 0x00 master · 0x01..0x08 zones (`HG_MAX_ZONES 8`) · 0xFE unassigned · 0xFF broadcast. Master never forwards (ring sink).
- ACK model §2.6: global stop-and-wait, one outstanding ACK_REQ frame ring-wide; tracked types CMD > FW_UPDATE > CFG_COMMIT ≈ CFG_GET (CMD/FW inserted ahead); 8-deep queue; `ack_timeout_ms = clamp(200 + 40·ring_size, 400, 900)`; 3 byte-identical attempts; UNCLAIMED unicast returning to master fails immediately (`ZONE_UNKNOWN`).
- Error tokens only from the spec §5.1 set (ring additions used here: `ZONE_TIMEOUT ZONE_OFFLINE ZONE_UNKNOWN ZONE_UNASSIGNED RING_DOWN WRONG_ZONE ID_CONFLICT MISSING_CHUNK FW_BUSY FW_NO_IMAGE`).
- Commits: conventional `type(scope): summary`, trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`, push after each task. Branch `main` (standing owner consent).
- IDF builds (tasks 11+): PowerShell, `& C:\esp\v6.0.1\esp-idf\export.ps1` first. Flashing ONLY via `tools/flash_all.py` / `tools/flash_app.py`. Bench: master COM17, zone COM24 (+ third board), ring wired 19→18 all around.

```c
#include <stddef.h>

#define RING_MAGIC          0xA1
#define RING_HDR_LEN        9
#define RING_MAX_PAYLOAD    128
#define RING_FRAME_MAX      (RING_HDR_LEN + RING_MAX_PAYLOAD + 2)   /* 139: hdr+payload+crc */

       RING_T_CMD = 0x10, RING_T_TIME_SYNC = 0x11, RING_T_ASSIGN_ID = 0x12, RING_T_CFG_CHUNK = 0x13,
```

```c
typedef struct { uint8_t src, dst, type, flags, ttl, len; uint16_t seq; } ring_hdr_t;

int  ring_frame_encode(const ring_hdr_t *h, const uint8_t *payload,
                       uint8_t *wire, size_t cap);
     /* builds 0x00 + COBS(hdr+payload+crc16le) + 0x00; returns wire length, or -1
        (len > 128, cap too small). h->len must equal the payload length. */

typedef struct { uint8_t buf[RING_WIRE_MAX]; uint16_t n; } ring_dec_t;
void ring_dec_init(ring_dec_t *d);
void ring_dec_reset(ring_dec_t *d);          /* on UART BREAK/error events */
int  ring_dec_feed(ring_dec_t *d, uint8_t byte, ring_hdr_t *h, uint8_t payload[RING_MAX_PAYLOAD]);
     /* 1 = complete valid frame in (h, payload); 0 = need more; -1 = frame dropped
        (bad COBS / magic / len mismatch / CRC / oversize) — decoder has resynced, caller counts. */
```

Decoder rules (spec §2.2): accumulate non-zero bytes between 0x00 delimiters (a 0x00 with an empty buffer is idle keep-scanning; with content it terminates the frame → COBS-decode → checks magic=0xA1, decoded length == RING_HDR_LEN + hdr.len + 2, CRC over hdr+payload equals the trailing LE crc). Buffer overrun (>141 content bytes without delimiter) → -1 + resync (discard until next 0x00).
